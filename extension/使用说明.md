# Edge 同步状态 使用说明 / Help

点工具栏里的图标，打开一个标签页，看这台电脑的同步有没有真的成功。已经打开过就直接切到那一页。

Click the toolbar icon to open a tab and check whether sync on this computer actually succeeded. If the tab is already open, Edge switches to it.

## 怎么启动 / How to start

1. 从 [v1.0.1 Release](https://github.com/LWS-CSDN/edge-sync-status/releases/tag/v1.0.1) 下载 [edge-sync-status-v1.0.1-windows-x64.zip](https://github.com/LWS-CSDN/edge-sync-status/releases/download/v1.0.1/edge-sync-status-v1.0.1-windows-x64.zip)，解压到准备长期保留的位置。Download [edge-sync-status-v1.0.1-windows-x64.zip](https://github.com/LWS-CSDN/edge-sync-status/releases/download/v1.0.1/edge-sync-status-v1.0.1-windows-x64.zip) from the [v1.0.1 release](https://github.com/LWS-CSDN/edge-sync-status/releases/tag/v1.0.1) and extract it to a location you intend to keep.
2. 打开 `edge://extensions/`，打开「开发人员模式」，选「加载解压缩的扩展」，指向解压出来的 `extension` 文件夹。Open `edge://extensions/`, turn on Developer mode, choose "Load unpacked", and select the extracted `extension` folder.
3. 双击解压目录里的 `注册.cmd`。看到 `Registered com.edge.syncstatus` 后，点工具栏图标启动。Double-click `注册.cmd` in the extracted folder. After `Registered com.edge.syncstatus` appears, click the toolbar icon to start it.

工具栏没有图标时，在 Edge「扩展」菜单中找到「Edge 同步状态」并固定。日常使用只需点击图标，点击「刷新」重新读取。读取程序由 Edge 按需启动，无需单独运行 EXE 或启动服务器。

If the icon is missing, find "Edge 同步状态" in Edge's Extensions menu and pin it. Click the icon to open the page and "刷新" (Refresh) to read again. Edge starts the reader on demand; do not launch the EXE or a separate server. The main status page uses Chinese labels; their English meanings are listed below.

## 页面上有什么 / What the page shows

**顶部的状态标记**回答最重要的一个问题：最近一次上传有没有被服务器接受。**The status marker at the top** answers whether the latest upload was accepted by the server.

| 标记 Marker | 含义 Meaning | 该怎么做 What to do |
|---|---|---|
| 同步正常 Sync OK | 最近一次上传被服务器接受了 The latest upload was accepted | 不用做任何事 Nothing |
| 同步卡住 Possibly stuck | 日志出现新客户端初始化且没有成功上传，可能仍在初始化 A new-client initialization appears without a successful upload; it may still be initializing | 稍后刷新，并结合 Edge 同步状态确认；此标记可能误报 Refresh later and check Edge's sync status; this marker can be a false positive |
| 最近无上传 No recent upload | 有过同步记录，但最近没有新的上传 Sync records exist, but there is no recent upload | 改动一个书签或设置，点页面上的「刷新」再看 Change a bookmark or setting, then click Refresh |
| 没有记录 No records | 没找到同步日志 No sync log was found | 确认这个配置文件开过同步 Confirm that sync was enabled for this profile |
| 读取失败 Read failed | 扩展没连上本机的读取程序 The extension could not connect to the local reader | 见下方「读取失败怎么办」 See "If reading fails" below |

标记下面的一行字写着上次成功上传的时间。The line under the marker shows the time of the last successful upload.

**各类数据最近一次成功上传**按类型分开看。收藏夹、历史记录、设置、打开的标签页各自记一笔，时间是服务器接受的那一刻。某一类长期不更新，说明只有这一类没传上去，其余是正常的。**Latest successful upload by data type** lists bookmarks, history, settings, and open tabs separately. The time is when the server accepted that upload. If one type stays old, only that type failed to upload.

**设备**列出这个账号下连过同步的设备，按最后出现的时间排列。**Devices** lists devices that have connected under this account, ordered by when they were last seen.

- 标红的是超过 14 天没有出现的设备，多半是旧电脑、重装过系统，或者已经不用的虚拟机。Red marks a device not seen for more than 14 days, often an old computer, a reinstalled system, or an unused virtual machine.
- 同一台电脑、同一个版本登记了不止一次时，会合并成一行，并注明重复登记了几次。Edge 每次重新登记设备都会留一条新记录，所以不合并的话一台电脑会占好几行。Repeated registrations of the same computer and version are merged into one row, with the repeat count shown. Edge creates a new record each time a device is registered again.

**最近的同步记录**是最近几次和服务器的通信，能看到传了哪些类型、结果是不是成功。排查时看这里。**Recent sync records** show recent exchanges with the server, including which types were sent and whether they succeeded. Use this section when troubleshooting.

## 它看得到什么，看不到什么 / What it can and cannot see

- 当前只读取 Edge 标准用户数据目录中的 Default 配置文件，暂不支持其他配置文件和自定义用户数据目录。It currently reads only the Default profile in Edge's standard user-data directory. Other profiles and custom user-data directories are not supported yet.
- 设备名称识别可能不完整；跨年日志时间及部分事件详情可能有解析偏差。Device-name recognition may be incomplete. Times crossing a year boundary, and some event details, may be parsed incorrectly.
- 只看这台电脑上的记录。手机和别的电脑要先连上同步、记录出现在这台电脑里，才会出现在设备列表里。It only sees records on this computer. A phone or another computer appears only after it has synced and its record exists here.
- 显示的是上传有没有被接受，不显示同步的具体内容，也不会改动任何同步数据。It shows whether an upload was accepted. It does not show synced content and does not change sync data.
- 时间都换算成本机时区。Times are shown in the local time zone.

## 读取失败怎么办 / If reading fails

「读取失败」表示扩展没能启动本机的读取程序，按顺序查："Read failed" means the extension could not start the local reader. Check these in order:

1. 使用 Windows 10/11 和 Microsoft Edge。发布包已经包含 `host/syncstatus-host.exe`，无需安装 Python；先完整解压发布包，不要直接在压缩包内运行。Use Windows 10/11 and Microsoft Edge. The release package already contains `host/syncstatus-host.exe`, so Python is not required. Extract the package completely; do not run it from inside the archive.
2. 在 `edge://extensions/` 打开开发人员模式，加载解压目录中的 `extension` 文件夹。扩展 ID 应为 `baihbjmdopjlikhppfbpgknmlijfkfgn`，无需手动填写或修改 ID。At `edge://extensions/`, turn on Developer mode and load the extracted `extension` folder. The extension ID should be `baihbjmdopjlikhppfbpgknmlijfkfgn`; do not enter or change it manually.
3. 在扩展所在目录的上一级双击 `注册.cmd`。它会检查本机程序和配置文件，再通过 Windows 自带的 `reg.exe` 登记当前用户的 Edge Native Messaging 主机，无需管理员权限。Double-click `注册.cmd` one level above the extension folder. It checks the local program and configuration, then uses Windows `reg.exe` to register the Edge native-messaging host for the current user. Administrator rights are not required.
4. 如果从旧版升级后 ID 不同，先在 `edge://extensions/` 移除旧扩展，再加载新版 `extension` 文件夹。移动解压目录后，重新加载扩展并再次运行 `注册.cmd`。If the ID differs after upgrading from an older build, remove the old extension at `edge://extensions/` and load the new `extension` folder. After moving the extracted folder, reload the extension and run `注册.cmd` again.
5. 若注册窗口报缺少文件，重新完整解压发布包；若报注册表写入失败，按窗口里的系统错误排查。注册入口不依赖 PowerShell 脚本，也无需修改脚本执行策略。If the registration window reports a missing file, extract the release package again. If it reports a registry write failure, follow the system error shown in the window. The registration entry does not depend on a PowerShell script or on changing the script execution policy.

卸载时，双击上一级目录的 `卸载.cmd` 删除当前用户的主机登记，再到 `edge://extensions/` 移除扩展。To uninstall, double-click `卸载.cmd` one level up to remove the current user's host registration, then remove the extension at `edge://extensions/`.

安装和卸载的完整步骤见上一级目录的 `README.md`，也可以看[在线说明](https://github.com/LWS-CSDN/edge-sync-status/blob/main/README.md)。The complete install and uninstall steps are in `README.md` one level up, and in the [online guide](https://github.com/LWS-CSDN/edge-sync-status/blob/main/README.md).
