## 启动扩展

1. 下载 [edge-sync-status-v1.0.5-windows-x64.zip](https://github.com/LWS-CSDN/edge-sync-status/releases/download/v1.0.5/edge-sync-status-v1.0.5-windows-x64.zip)，完整解压到准备长期保留的文件夹。
2. 打开 `edge://extensions/`，打开「开发人员模式」，选择「加载解压缩的扩展」，选中包内的 `extension` 文件夹。
3. 双击该文件夹上一级的 `install.cmd`。看到 `Registered com.edge.syncstatus` 后，点击工具栏中的扩展图标。

如果看不到图标，在 Edge「扩展」菜单中找到「Edge 同步状态」并固定。点击图标会打开状态页，已经打开时切换到原标签页；点击「刷新」重新读取本地记录。读取程序由 Edge 按需启动，无需单独运行 EXE 或启动服务器。

发布包需要 Windows 10/11 x64 和 Microsoft Edge 120 或更新版本，不需要 Python 或管理员权限，暂不支持 macOS 和 Linux。

## 切换界面语言

从 v1.0.2 起，状态页和帮助页均支持中英文切换。右上角按钮显示可以切换到的语言：中文页面显示 **English**，英文页面显示 **中文**。

首次使用跟随 Edge 的界面语言：中文环境使用中文，其余使用英文。手动选择会保存在本机，重新打开后仍然生效。状态页和帮助页共用设置，已打开的页面会一起更新，每次只显示一种语言。

Markdown 文档通过每个文件顶部的语言链接切换，在解压后的安装包中也可以使用。

## 看懂报告

### 状态与最近成功上传时间

顶部状态标记概括本机同步记录，下方显示最近一次成功上传的时间。

| 状态 | 含义 | 建议操作 |
|---|---|---|
| 同步正常 | 最近一次上传被服务器接受。 | 此标记没有提示需要操作的问题。 |
| 同步卡住 | 日志出现新客户端初始化且没有成功上传，可能还在初始化。 | 等待后刷新，并结合 Edge 自带同步状态确认；此标记可能误报。 |
| 最近无上传 | 有同步记录，但没有近期上传。 | 小幅修改一个书签或设置，等待 Edge 同步后刷新。 |
| 没有记录 | 没有找到同步日志。 | 确认支持的配置文件已启用同步。 |
| 读取失败 | 扩展未能连接本机读取程序。 | 按下方排障步骤检查。 |

### 各类数据的上传时间

收藏夹、历史记录、设置和打开的标签页分别记录最近一次成功上传的时间，表示服务器接受该类上传的时刻。某类时间较早，也可能只是近期没有新改动，不能单凭这一点确认故障。

### 设备

设备列表来自本机已有记录，按最后一次出现的时间排列。

- 红色表示超过 14 天未出现，可能是旧电脑、重装过的系统或不再使用的虚拟机。
- 相同设备名称、相同版本的重复登记会合并成一行，并显示登记次数。
- 列表中没有某台设备，可能只是本机数据库中还没有它的记录。

### 近期同步事件

显示近期与服务器通信时涉及的数据类型、结果和事件详情。遇到意外状态时，可以结合这里的记录和 Edge 自带同步设置排查。

## 读取失败怎么办

按下面的顺序检查：

1. 完整解压发布包，确认 `host/syncstatus-host.exe` 和 `host/com.edge.syncstatus.json` 存在，不要在 ZIP 内直接运行安装脚本。
2. 在 `edge://extensions/` 加载包内的 `extension` 文件夹。扩展 ID 应为 `baihbjmdopjlikhppfbpgknmlijfkfgn`，不需要手动配置 ID。
3. 运行安装包顶层目录的 `install.cmd` 并检查结果。它通过 Windows 自带的 `reg.exe` 为当前用户登记原生消息宿主。
4. 如果移动过目录，从新位置重新加载扩展，并再次运行 `install.cmd`。旧安装的 ID 不同时，先移除旧扩展，再加载当前版本。
5. 提示缺少文件时，重新完整解压；注册表错误按安装窗口中的系统提示排查。也请检查读取程序是否被安全软件隔离。登记不需要修改 PowerShell 执行策略。

安装和升级的完整步骤见[中文 README](../README.zh-CN.md)，也可阅读[在线版本](https://github.com/LWS-CSDN/edge-sync-status/blob/main/README.zh-CN.md)。

## 报告能说明什么

- 当前只读取 Edge 标准用户数据目录中的 **Default 配置文件**，暂不支持其他配置文件和自定义目录。
- 报告展示本机诊断记录，不展示同步的具体内容，也不修改同步数据。
- 手机和其他电脑只有在本机出现对应记录后才会显示。
- 时间使用本机时区，跨年时间、部分事件详情和设备名称可能存在解析偏差。
- 「同步卡住」只是推断，请结合后续记录和 Edge 自带状态判断，再决定是否需要修复同步。

## 卸载

先在 `edge://extensions/` 移除扩展，再运行安装包顶层目录的 `uninstall.cmd`，移除当前用户的宿主登记。之后可以删除解压目录。
