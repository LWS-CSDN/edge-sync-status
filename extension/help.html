使用说明 / Help

点工具栏里的图标，打开一个标签页，看这台电脑的同步有没有真的成功。已经打开过就直接切到那一页。

Click the toolbar icon to open a tab and check whether sync on this computer actually succeeded. If the tab is already open, Edge switches to it.

怎么启动 / How to start

  1. 从 v1.0.1 Release 下载 edge-sync-status-v1.0.1-windows-x64.zip，解压到准备长期保留的位置。

    Download edge-sync-status-v1.0.1-windows-x64.zip from the v1.0.1 release and extract it to a location you intend to keep.

  2. 打开 edge://extensions/，打开「开发人员模式」，选「加载解压缩的扩展」，指向解压出来的 extension 文件夹。

    Open edge://extensions/, turn on Developer mode, choose "Load unpacked", and select the extracted extension folder.

  3. 双击解压目录里的 注册.cmd。看到 Registered com.edge.syncstatus 后，点工具栏图标启动。

    Double-click 注册.cmd in the extracted folder. After Registered com.edge.syncstatus appears, click the toolbar icon to start it.

工具栏没有图标时，在 Edge「扩展」菜单中找到「Edge 同步状态」并固定。日常使用只需点击图标，点击「刷新」重新读取。读取程序由 Edge 按需启动，无需单独运行 EXE 或启动服务器。

If the icon is missing, find "Edge 同步状态" in Edge's Extensions menu and pin it. Click the icon to open the page and "刷新" (Refresh) to read again. Edge starts the reader on demand; do not launch the EXE or a separate server. The main status page uses Chinese labels; their English meanings are listed below.

顶部的状态标记回答最重要的一个问题：最近一次上传有没有被服务器接受。

The status marker at the top answers the most important question: whether the latest upload was accepted by the server.

标记下面的一行字写着上次成功上传的时间。

The line under the marker shows the time of the last successful upload.

各类数据最近一次成功上传按类型分开看。收藏夹、历史记录、设置、打开的标签页各自记一笔，时间是服务器接受的那一刻。某一类长期不更新，说明只有这一类没传上去，其余是正常的。

Latest successful upload by data type lists bookmarks, history, settings, and open tabs separately. The time is when the server accepted that upload. If one type stays old, only that type failed to upload.

设备列出这个账号下连过同步的设备，按最后出现的时间排列。

Devices lists devices that have connected under this account, ordered by when they were last seen.

  • 标红的是超过 14 天没有出现的设备，多半是旧电脑、重装过系统，或者已经不用的虚拟机。Red marks a device not seen for more than 14 days, often an old computer, a reinstalled system, or an unused virtual machine.
  • 同一台电脑、同一个版本登记了不止一次时，会合并成一行，并注明重复登记了几次。Edge 每次重新登记设备都会留一条新记录，所以不合并的话一台电脑会占好几行。Repeated registrations of the same computer and version are merged into one row, with the repeat count shown. Edge creates a new record each time a device is registered again.

最近的同步记录是最近几次和服务器的通信，能看到传了哪些类型、结果是不是成功。排查时看这里。

Recent sync records show recent exchanges with the server, including which types were sent and whether they succeeded. Use this section when troubleshooting.

它看得到什么，看不到什么 / What it can and cannot see

  • 当前只读取 Edge 标准用户数据目录中的 Default 配置文件。其他配置文件（如 Profile 1）和自定义用户数据目录暂不支持。It currently reads only the Default profile in Edge's standard user-data directory. Other profiles (such as Profile 1) and custom user-data directories are not supported yet.
  • 设备名称识别可能不完整；跨年日志时间及部分事件详情可能有解析偏差。Device-name recognition may be incomplete. Times crossing a year boundary, and some event details, may be parsed incorrectly.
  • 只看这台电脑上的记录。手机和别的电脑要先连上同步、记录出现在这台电脑里，才会出现在设备列表里。It only sees records on this computer. A phone or another computer appears only after it has synced and its record exists here.
  • 显示的是上传有没有被接受，不显示同步的具体内容，也不会改动任何同步数据。It shows whether an upload was accepted. It does not show synced content and does not change sync data.
  • 时间都换算成本机时区。Times are shown in the local time zone.

系统要求 / Requirements

  • Windows 10 或 Windows 11，64 位。不需要安装 Python。Windows 10 or Windows 11, 64-bit. Python is not required.
  • macOS 和 Linux 暂不支持，读取程序目前只有 Windows 版。macOS and Linux are not supported yet; the reader is currently Windows-only.

读取失败怎么办 / If reading fails

「读取失败」表示扩展没能启动本机的读取程序，按顺序查：

"Read failed" means the extension could not start the local reader. Check these in order:

  1. 确认运行过解压目录里的 注册.cmd，窗口里出现过「Registered com.edge.syncstatus」。Confirm that 注册.cmd was run from the extracted folder and showed "Registered com.edge.syncstatus".
  2. 确认 host 文件夹里有 syncstatus-host.exe，没有被杀毒软件隔离。Confirm that syncstatus-host.exe is in the host folder and was not quarantined by antivirus software.
  3. 把整个目录挪了位置之后，要重新运行一次 注册.cmd。After moving the whole folder, run 注册.cmd again.

The complete install and uninstall steps are in README.md one level up, and in the online guide.
