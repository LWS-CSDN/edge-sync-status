使用说明

点工具栏里的图标，打开一个标签页，看这台电脑的同步有没有真的成功。已经打开过就直接切到那一页。

页面上有什么

顶部的状态标记回答最重要的一个问题：最近一次上传有没有被服务器接受。

标记含义该怎么做
同步正常最近一次上传被服务器接受了不用做任何事
同步卡住日志中出现新客户端初始化且没有成功上传，可能尚未完成初始化稍后刷新，并结合 Edge 的同步状态确认；此标记可能误报
最近无上传有过同步记录，但最近没有新的上传改动一个书签或设置，点页面上的「刷新」再看
没有记录没找到同步日志确认这个配置文件开过同步
读取失败扩展没连上本机的读取程序见下方「读取失败怎么办」

标记下面的一行字写着上次成功上传的时间。

各类数据最近一次成功上传按类型分开看。收藏夹、历史记录、设置、打开的标签页各自记一笔，时间是服务器接受的那一刻。某一类长期不更新，说明只有这一类没传上去，其余是正常的。

设备列出这个账号下连过同步的设备，按最后出现的时间排列。

  • 标红的是超过 14 天没有出现的设备，多半是旧电脑、重装过系统，或者已经不用的虚拟机。
  • 同一台电脑、同一个版本登记了不止一次时，会合并成一行，并注明重复登记了几次。Edge 每次重新登记设备都会留一条新记录，所以不合并的话一台电脑会占好几行。

最近的同步记录是最近几次和服务器的通信，能看到传了哪些类型、结果是不是成功。排查时看这里。

它看得到什么，看不到什么

  • 当前只读取 Edge 标准用户数据目录中的 Default 配置文件。其他配置文件（如 Profile 1）和自定义用户数据目录暂不支持。
  • 设备名称识别可能不完整；跨年日志时间及部分事件详情可能有解析偏差。
  • 只看这台电脑上的记录。手机和别的电脑要先连上同步、记录出现在这台电脑里，才会出现在设备列表里。
  • 显示的是上传有没有被接受，不显示同步的具体内容，也不会改动任何同步数据。
  • 时间都换算成本机时区。

系统要求

  • Windows 10 或 Windows 11，64 位。不需要安装 Python。
  • macOS 和 Linux 暂不支持，读取程序目前只有 Windows 版。

读取失败怎么办

「读取失败」表示扩展没能启动本机的读取程序，按顺序查：

  1. 确认运行过解压目录里的 注册.cmd，窗口里出现过「Registered com.edge.syncstatus」。
  2. 确认 host 文件夹里有 syncstatus-host.exe，没有被杀毒软件隔离。
  3. 把整个目录挪了位置之后，要重新运行一次 注册.cmd。

安装和卸载的完整步骤见上一级目录的 README.md。
