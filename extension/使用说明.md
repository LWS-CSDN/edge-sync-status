# Edge 同步状态 使用说明

点工具栏里的图标，打开一个标签页，看这台电脑的同步有没有真的成功。已经打开过就直接切到那一页。

## 页面上有什么

**顶部的状态标记**回答最重要的一个问题：最近一次上传有没有被服务器接受。

| 标记 | 含义 | 该怎么做 |
|---|---|---|
| 同步正常 | 最近一次上传被服务器接受了 | 不用做任何事 |
| 同步卡住 | 日志出现新客户端初始化且没有成功上传，可能仍在初始化 | 稍后刷新，并结合 Edge 同步状态确认；此标记可能误报 |
| 最近无上传 | 有过同步记录，但最近没有新的上传 | 改动一个书签或设置，点页面上的「刷新」再看 |
| 没有记录 | 没找到同步日志 | 确认这个配置文件开过同步 |
| 读取失败 | 扩展没连上本机的读取程序 | 见下方「读取失败怎么办」 |

标记下面的一行字写着上次成功上传的时间。

**各类数据最近一次成功上传**按类型分开看。收藏夹、历史记录、设置、打开的标签页各自记一笔，时间是服务器接受的那一刻。某一类长期不更新，说明只有这一类没传上去，其余是正常的。

**设备**列出这个账号下连过同步的设备，按最后出现的时间排列。

- 标红的是超过 14 天没有出现的设备，多半是旧电脑、重装过系统，或者已经不用的虚拟机。
- 同一台电脑、同一个版本登记了不止一次时，会合并成一行，并注明重复登记了几次。Edge 每次重新登记设备都会留一条新记录，所以不合并的话一台电脑会占好几行。

**最近的同步记录**是最近几次和服务器的通信，能看到传了哪些类型、结果是不是成功。排查时看这里。

## 它看得到什么，看不到什么

- 当前只读取 Edge 标准用户数据目录中的 Default 配置文件，暂不支持其他配置文件和自定义用户数据目录。
- 设备名称识别可能不完整；跨年日志时间及部分事件详情可能有解析偏差。
- 只看这台电脑上的记录。手机和别的电脑要先连上同步、记录出现在这台电脑里，才会出现在设备列表里。
- 显示的是上传有没有被接受，不显示同步的具体内容，也不会改动任何同步数据。
- 时间都换算成本机时区。

## 读取失败怎么办

「读取失败」表示扩展没能启动本机的读取程序，按顺序查：

1. 使用 Windows 10/11 和 Microsoft Edge。发布包已经包含 `host/syncstatus-host.exe`，无需安装 Python；先完整解压发布包，不要直接在压缩包内运行。
2. 在 `edge://extensions/` 打开开发人员模式，加载解压目录中的 `extension` 文件夹。扩展 ID 应为 `baihbjmdopjlikhppfbpgknmlijfkfgn`，无需手动填写或修改 ID。
3. 在扩展所在目录的上一级双击 `注册.cmd`。它会检查本机程序和配置文件，再通过 Windows 自带的 `reg.exe` 登记当前用户的 Edge Native Messaging 主机，无需管理员权限。
4. 如果从旧版升级后 ID 不同，先在 `edge://extensions/` 移除旧扩展，再加载新版 `extension` 文件夹。移动解压目录后，重新加载扩展并再次运行 `注册.cmd`。
5. 若注册窗口报缺少文件，重新完整解压发布包；若报注册表写入失败，按窗口里的系统错误排查。注册入口不依赖 PowerShell 脚本，也无需修改脚本执行策略。

卸载时，双击上一级目录的 `卸载.cmd` 删除当前用户的主机登记，再到 `edge://extensions/` 移除扩展。

安装和卸载的完整步骤见上一级目录的 `README.md`。
